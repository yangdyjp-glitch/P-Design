# 0.3.1：每张图独立的补充要求

右侧「本图补充要求」属于当前选中的一张图。每张图使用自己的 `requirements` 字段，切页、云端保存、项目备份与导入均保留这份文本。旧版 `project.brief` 保留为整套初始背景，不自动复制到每张图，避免把旧要求误分配给某一图。

## 使用

1. 在左侧选择要修改的图。
2. 填写本图要求，例如「本图照片完整显示，不要裁切」。
3. 点击输入框下的「发送并修改本图」，或按 Ctrl / ⌘ + Enter。
4. AI 只制作、渲染和检查这张图，通过后自动更新。其他图的文案、版式、图片和补充要求保留。

输入即保存，发送才开始修改。空白要求不能发送；已有任务处理时显示等待原因，避免重复提交。顶部「AI 设计整套」仍用于整套重新设计，新建时的「整套初始方向」与逐图要求分开。

## 范围约束

- 单图请求为 `kind: revise`、`workflow: automatic`、`scope: page`，`pageIds` 必须只有当前一页。
- 服务端仅从已保存项目取该页的原文和要求，不把其他页放入该任务的锁定文案。
- 单图结果必须返回同一页 ID、相同文字与顺序，不能新增、删除、重新分页或返回其他页。
- 浏览器只合并目标页的 HTML/CSS 和图片安排，检查也只针对该页；不替换整个项目的页面数组。
- 自动修正继承原单图范围，不能变为整套或切换目标。一次修正上限、原文检查、资源权限和版本冲突保护继续生效。
- 优先保留目标页已使用的图片，再补充最近上传的素材，避免较早的在用图片被最近上传列表挤掉。
- 每张图记录最近应用的 AI 任务，修改第二张后仍能正确识别第一张已经应用的结果，避免刷新后重复应用。
- 导入备份会保留各图要求，并重置原云端版本、冲突状态及旧任务标记，作为新项目保存；旧版备份也适用。
