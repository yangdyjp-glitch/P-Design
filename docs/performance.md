# 0.5.7 载入与 AI 交付优化

2026-11-09。本轮目标是减少重复读取、渲染、安装和文件传输，保留原有设计模型、14 个技能目录及全部质量检查。没有数据库迁移、付费模型降级或新增用户视觉设置。

## 入口与实现

- `server/routes.ts` 的 `/api/workspace` 合并会话、当前账户项目及最近 30 个任务，沿用身份认证、账户隔离和不缓存私有响应的规则。访客只得到空工作空间。已完成任务仅返回摘要；打开详情或需要应用方案时，网页再读取原有 `/api/jobs/:id`，旧 API 完整保留。
- `src/cloud.js` 消费一次首屏项目数据，详情载入后继续进行版本保护、实际网页检查与应用。身份变化时中止请求并清空尚未使用的项目缓存。
- `src/app.js` 同时读取画面样式；切页仅更新当前画面、文案及单图要求，不重建全部缩略图。缩略图按可见区域附近加载，观察器与异步字体回调在身份/画面变化后失效。切换项目不制造无内容修改的保存，上一项目未同步修改仍入保存队列。
- 修正原先没有匹配到 `.ttf` 的替换式。生产旧字体 TTF 请求实际返回 404，不能把完整字体文件体积称为旧版真实下载量。
- `src/preview-fonts.js` 和生成清单让网页按需加载 6356 字符子集，完整字体覆盖其他字符。子集新名称为 TuXu Preview Sans，四字重共 3,335,888 字节，完整四字重共 16,702,200 字节。保留字宽、单位尺度和许可；哈希文件名配合 `public/_headers` 的一年缓存，完整文件采用一周缓存。正式 PNG 嵌入完整所用字重，离线工程仍带四份完整字体与许可。
- `server/agent.ts` 新任务的 `renderRuntime.version=2` 不再复制字体、重复字体 ZIP；可下载 HTML 引用服务端公开字体，网站的可编辑工程下载仍完全离线。原任务/旧快照保留原文件交付方式。
- 托管环境只预装 Node Playwright Chromium 及系统依赖，不同时安装第二套 Python 浏览器。特定 Python 渲染器确有需要时仍可安装所需浏览器。单页当前 HTML 引用的图片立即提供，其他本项目照片保留目录并在 AI 请求时上传；整套上传模式仍提供且必须使用全部上传图。取消与失败清理私有文件。
- `server/artifacts.ts` 文件最多两路并行，普通批次估计总大小不超过 12 MiB，大文件单独获取；保留 24 件、单件 25 MiB、合计 35 MiB 的上限及单图检查证据优先级。失败等待同批次完成并回滚已复制内容。

## 实测边界

线上旧版接口每次约 1.5–1.8 秒。新首屏避免原先会话 → 任务 → 项目的三次顺序请求和重复数据库连接；仍需经历登录、数据库及用户网络延迟。

真实浏览器、同一七页项目、每次 API 固定 500 ms 的受控比较：工作台框架出现 1749 → 628 ms；当前画面字体就绪 2226 → 1037 ms。一次切页原先重载 8 个 iframe，新版仅重载当前 1 个，其他缩略图 0 个；该轮切页时间 219 → 234 ms，不能声称单次切页计时更快。前后分别使用旧版失败的 TTF 请求和新版实际字体，已明确这一区别。

字体生成逐一核对各字重全部 6356 字符的横向指标、169 个抽样轮廓，均一致。浏览器同页使用完整 WOFF2 与子集时，360×480 对照截图的像素通道差异为 0。离线 ZIP 实际下载核对，四个完整字体逐字节一致，HTML 不依赖预览子集。

一个独立项目执行真实付费单图修改，沿用原第 03 张母版与「让排版更加易读一些。」、预案一及两张原实拍。两张未引用照片保留可选目录，本轮无需上传；原文、顺序、页数及另一整页逐字段不变。服务端与网页检查 passed，0 次修正，托管会话删除核验通过。交付 12 件文件、711856 字节；先前同类样例为 17433695 字节。实际总耗时 252295 ms，交付 6710 ms；旧同类样例 269131 ms。单次 AI 任务存在模型、环境和网络波动，这些数据不构成普遍提速比例，主要耗时仍是 AI 设计与渲染检查。

`result.timings` 记录输入准备、会话创建、交付前累计、文件传输和总耗时；交付前累计包含排队、安装、设计、渲染、检查与轮询等待，不能单独当作模型推理时间。证据在执行机忽略目录 `qa/railway/performance/` 及工作区 `deliverables/performance/`。

## 字体再生成

`scripts/build-preview-fonts.py` 需要本地 Python、FontTools 4.60.1 与 Brotli。默认构建使用已提交字体，不需要 Python 或联网生成。只有修改字表/原字体时才重新运行，核验生成文件与 `src/preview-fonts.json`、`src/preview-font-data.js` 一致、许可、指标及浏览器视觉，并删除不再引用的派生文件；不要删除完整原字体。

上线仍以 Railway 部署、实际服务提交、账户登录、首屏数据、字体缓存及已有项目/图片留存核验为准；不把本地计时直接当成用户网络上的首屏时间。
