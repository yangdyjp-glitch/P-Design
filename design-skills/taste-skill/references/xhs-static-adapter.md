# 静态平面设计适配

适用：固定画布的小红书封面、内页、海报与单页修改。此模式借鉴上游 Taste 的视觉方法，不运行公司网站的完整构建流程。

## 需要实际采用的判断

1. 先判断内容要让读者看懂什么，再决定第一焦点与阅读顺序。主视觉可以是标题、真实照片或信息关系；照片不因存在就自动成为大幅主图。
2. 从 layout-v4 的构图类型、equal edges / grid 与 type 中选择适合的关系：共同边线、有目的的偏轴、清楚的主次、连贯的中文断行。按固定画布与实际内容调整数值。
3. 从 system 的节奏、字级、对比和一致性中建立精简视觉规则。使用本次可用且已加载的字体，不新增外部字体请求。保持系列身份，按每页内容变化构图，不机械复制同一块模板。
4. 明确每个空白区的用途，兼顾阅读密度；不以大片空底代替构图，也不靠嵌套卡片、贴纸和无意义标记填满页面。
5. 原图主体与画内文字保持真实可辨；图框服务于内容与照片比例。图片来源、上传图裁剪限制和纯文字模式由本次任务控制。
6. 查看实际母版与约 360px 宽阅读图：焦点是否明确、下一步是否自然、正文是否可读、图文比例是否合适、边线是否统一、疏密是否有意图。依据实际证据修正，不把技术合格称为审美保证。

## 本次任务约束优先

已确认文案逐字保留；明确分页保持原页数、顺序和原页归属，让图片适配页面。不得为了上游样例的画面或照片配额删改文案、拆页或新增页。
采用本次确认的品牌色、字体、画布和素材范围，不重新抽取随机调色板，不增加品牌名、标签、CTA、说明文字或事实。不得猜测营业时间、价格、联系方式或资历。
静态交付不采用滚动、hover、WebGL、入场动效、固定导航、网页表单或每屏一章节规则；不把网页像素、网页字重限制和屏幕高度照搬到图片。
上游“图片下不得有说明”、固定照片数量、强制照片、删除地址或改为 .example 仅属于其公司网站约定；不能删掉本次原稿或突破任务的图片来源方式。
不要用技能自带图库、样例 URL 或网络下载绕过本应用配图工具。来源受限时借鉴排版方法，不应用未经授权的照片或生成图片。
照片与纯文字两类方案均可使用 Taste；纯文字模式依靠字级、空间、色块和线条，不预留空照片槽。
