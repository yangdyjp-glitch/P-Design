# 小红书参考转规范

本地适配自 OpenDesign Reference Design Contract。这里服务静态封面和图文组图；本次用户要求、品牌规范和文案优先。

## 从参考形成决定

1. 确定本次输出形态、读者、内容模式、已有素材和修改范围。信息够用即继续。
2. 查看实际参考，分清用户提供、已观察和推断；记录来源，不能把没有看过的图片写成已分析。
3. 每个参考拆成三项：**保留**可学习的层级、比例、节奏和材质关系；**改变**主题、文字、素材和不合本次要求的结构；**不可照搬**作者身份、独占素材、事实承诺、标志和完整成品。
4. 将“饱满、杂志感、清晰”等词落实到标题与主图比例、网格、色彩角色、字重、留白用途和页面节奏。观察不能量化时如实描述，不编造测量值。
5. 形成一个与内容相符的方向，明确字体、配色、间距、图片处理和整套共性。仅有真正影响执行的缺口时询问，不强制输出多个互不相关的方向。

## 记录尺度

简单任务在当前项目简报中记录关键决定。复杂或交接任务可写 `DESIGN.md`，包含视觉主题、色彩、字体、间距网格、构图、图片处理、文案边界和验收条件；不强制网页的导航、组件、动效或九段格式。

交接说明至少让下一步知道：使用哪些文件、本次锁定什么、每页要表达什么、哪些素材可用，以及怎样判定完成。

交接前使用 [检查清单](references/checklist.md)。不要把示例中的品牌、价格、字体、配色或页数带入新任务。
