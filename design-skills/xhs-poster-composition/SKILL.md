# 小红书海报构图

本地适配自 Arnav Puri Poster Design 的构图和文字层级方法；正式文字采用可编辑排版，不继承上游默认的整图生成后端、字体示例或印刷尺寸。

## 选择与内容相符的结构

先写出每页的主要阅读任务、主视觉和先后顺序，再选择结构：

| 结构 | 更适合的内容 | 检查重点 |
|---|---|---|
| 主视觉与大标题 | 单一结论、封面或一个可见结果 | 视觉中心清楚，主图与标题互相支持 |
| 图文分区 | 解释与示例、照片与说明 | 两区比例按文字和主体决定，不机械对半 |
| 网格与模块 | 清单、分组、结构化知识 | 仅真正同类的信息等权排列 |
| 对比 | 两个有依据的选项或状态 | 比较口径一致，关键差异容易找到 |
| 步骤或路径 | 教程、过程和有序操作 | 顺序与连接关系清楚，标签不与正文抢权重 |
| 叠压与错位 | 需要图文前后关系或编辑感 | 不遮正文、不压关键主体，层次有因 |

结构是可组合的工具，不是必须套用的模板。不要默认居中、默认渐变、默认圆角卡片或默认照片拼贴。

## 四级文字角色

区分主标题、次级标题、连续正文和必要辅助信息。通过大小、字重、颜色、位置和邻近关系建立层级；没有对应内容的角色不需要补造文字。

字体依本次方案；同一字体不同字重即可形成层次。中文断行按语义组织，连续正文不逐字旋转或拉伸，不照搬英文大写、负字距和首字下沉。

## 图文与节奏

根据图片实际主体设置裁切和文本位置。来源照片不强制套滤镜；实拍、截图和生成示意的角色按本次任务区分。

先解决主图比例、文字区宽度与分区间距，再考虑纸边、线条、阴影等细节。空白用于分组和聚焦，饱满来自信息与主视觉的分量，不来自装饰数量。

整套共享基础字体、配色角色和间距；页面结构因内容变化。固定原文放不下时增页或调整网格，不暗删或把字号压到手机上难读。

完成后转入 `xhs-design-polish`，查看实际渲染及手机预览。
