# 小红书封面判断

本地适配自 XHS Cover Lab Open。分析封面在当前内容、读者和素材下是否成立，不承诺点击率或爆款。

## 工作方式

1. 明确本次是分析已有封面、选择封面结构、改编参考还是制作封面简报。
2. 有图片时实际查看主体、关键词、标题层次、可见证据、情绪与信息密度。没有图片时从已提供主题和素材继续，不假称已观察。
3. 按需读以下一个或多个参考，不把行业举例变成固定主题或固定风格。
   - [封面结构类型](references/cover_archetypes.md)：判断视觉主体和内容结构。
   - [内容与结构匹配](references/track_router.md)：内容与素材如何支持封面选择。
   - [参考判断](references/benchmark_rules.md)：分清可学习结构、不可照搬资源和公开数据的边界。
   - [封面简报](references/cover_brief_contract.md)：向制作环节交接。
4. 给出适合本次任务的推荐结构和理由，需要时提供一个备选；不默认让用户在大量选项里重新做决定。
5. 锁定封面文字、主体、位置、色彩与字体方向、真实证明和检查条件，再交给构图环节。

## 内容边界

用户原文锁定时只安排层级和断行，不自动补写更刺激的标题。用户授权创作时可写标题，但不能制造效果、收入、测评、证言、稀缺性或身份。

参考作者的脸、房间、设备、经历、资质和已有影响力不能作为本次用户的事实。可学习主次、标题起点、分区与证明关系，不照搬完整作品。

当前素材不需要人物、价格、地点或产品时不强制添加。只有用户要求查近期样本或指标时再检索并注明核对时间；无法获取就说明范围，不能编造互动数据。

封面交付必须查看缩略图与打开阅读的效果。外部API、付费服务、账号操作和图片生成不是本技能的前置依赖；用户需要相关能力时按当前环境与明确要求处理。
