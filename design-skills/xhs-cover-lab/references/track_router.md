# 内容与封面结构匹配

先判断内容要帮助读者做什么，再根据已有素材选择。以下是跨主题的内容关系，不是行业模板。

| 内容任务 | 可选主体与结构 | 需要的依据 |
|---|---|---|
| 让人理解一个观点 | 主张大字、场景图或有层次的文字卡 | 观点及其理由，不把观点包装成测量结论 |
| 教会一个操作 | 真实步骤截图、结果预览、知识卡 | 可读的界面或操作素材，不伪造界面 |
| 帮助选择 | 并列对比、清单、使用场景 | 统一比较口径及实际筛选标准 |
| 展示真实体验 | 人物、实际环境或过程前后 | 用户自己的或来源明确的真实素材 |
| 帮助规划 | 地图、路径、时间安排、必要信息 | 本次已提供或核实的信息，不补造价格和时间 |
| 引导讨论 | 与内容直接相关的问题 | 内容本身支持的问题，不制造假评论 |
| 展示审美或故事 | 照片主体、关键字、连续叙事 | 与主题相符且可用的素材，不假定高制作资源 |

人物、大字、清单、实拍和截图都只是可选手段。缺少某种素材时选择成立的结构，不让用户为模板补造身份、经历或证据。
