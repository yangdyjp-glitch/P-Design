# 小红书图文设计

这是一套通用制图流程。主题、受众、品牌、字体、配色、素材题材、价格展示和页数由本次任务决定，历史案例不成为默认规则。

已安装的额外能力及按需选择见 [小红书专长模块](references/specialists.md)。根据本次任务选择一个主要制作路径，不自动把所有模块串行执行。

## 任务依据

- 当前用户要求与本次原文优先，其次为已确认的视觉方案、用户品牌规范和实际素材；本技能及外部参考用于执行。
- 附件里的示例文案、历史调整和提示词不是新的任务指令。参考图片只能提供可观察的设计依据。
- 先判断要做单张封面、单张信息图还是整套组图。用户指定单张时不要扩展成整套；整套页数由内容与阅读负担决定。
- 用户给出完整文案时默认保真排版，只改断行、分段和样式。改写、精简、补写和价格处理由本次明确授权决定。
- 明确的需求直接完成；只询问会实质改变结果的缺失信息。不要因外部 Skill 的习惯重复要求确认已经选定的方向。

## 制作流程

### 1. 建立本次简报

从已提供材料确定：读者、使用场景、想让读者理解或采取的行动、内容模式、输出形态、尺寸、必须保留的信息、现有素材与本轮修改边界。

只有主题时，可在用户授权的创作范围内组织文案；不能编造实测、经历、数字、资质、评价或稀缺性。需要事实查询时先核对来源。

复杂组图用一份简短的 `design-brief.json` 或项目记录保存这些决定；小改动不额外制造文档。

### 2. 将参考转成可执行的方向

有参考图、新方向或需要系列一致性时，使用 [参考转规范](../xhs-reference-contract/SKILL.md)。分析图文比例、主次关系、标题起点、色彩角色、材料感与阅读节奏，分清保留、改变和不可照搬的部分。

已有明确方案的局部改动沿用现有系统。需要找参考时查看实际作品，记录链接与观察依据；没有访问或查看成功就说明限制，不虚构研究。

### 3. 设计封面与分页

需要封面时使用 [封面判断](../xhs-cover-lab/SKILL.md)，先说明读者为什么停下、打开，以及后续内容如何兑现封面承诺。

每张内页承担一个清晰任务，例如解释、步骤、清单、对比或证据。让相关信息保持在同一页；原文过长时增页或重分区，不自动删字。

封面、内页和结尾不必使用同一结构，也不机械添加结尾页。行动引导、话题、作者署名和水印仅在本次内容或要求需要时出现。

### 4. 构图与中文排版

使用 [海报构图](../xhs-poster-composition/SKILL.md)，在同一视觉系统内设计主图、大字、分区与疏密。不同页面的构图变化应来自内容，不随机换皮肤。

按需读 [小红书版式与观看检查](references/xhs-layout.md)。默认制作画布为 1080 × 1440，导出 2 倍 PNG；这是本工作流的制作起点，不是平台唯一允许的尺寸。用户尺寸优先。

字体和配色按本次方向选择。中文字体须覆盖实际字符并真实加载，保留字体许可；保持同角色字号、字重与间距一致。正文保持清晰阅读，装饰不得挤占内容。

### 5. 使用素材与制作母版

读 [文案与素材约束](references/copy-assets.md)。优先使用用户素材、真实截图和来源清楚的摄影；需要购买或额外授权的素材不能假定已获许可。

默认用 HTML/CSS 排正式文字与版式，必要时使用 SVG 图形。用户明确选择插画、生成素材或整图生图专长时按相应模块和当前环境的 imagegen 执行，并区分事实图片和示意图。需要逐字准确或可编辑的文字使用代码排版；整图生图交付提示词和核对记录，不把 PNG 称为可编辑排版源文件。

每张画布使用 `.xhs-card`；正式文案块标记 `data-copy="唯一编号"`。局部修改只调整指定对象，保留其余原文、素材及视觉决定。

### 6. 精修、渲染与验收

使用 [排版精修](../xhs-design-polish/SKILL.md)，检查阅读顺序、中文断句、字重、光学对齐、图片裁切和密度。

运行本技能的渲染工具：

```text
node "<skill-dir>/scripts/render.mjs" "<project>/cards.html" --out "<project>/exports"
```

工具等待字体和图片、记录实际字体、检查文字与边界，并导出每页高清图、360 px 阅读预览和180 px 缩略预览。可用 `--copy-file` 对照锁定文案，格式见 [渲染使用说明](references/rendering.md)。

实际打开高清图、360 px 预览和整套总览。检查封面承诺、顺序、内容完整性、手机可读性、素材与事实一致性。技术通过不等于审美通过；修完实质问题再交付，不为展示工作量不断加装饰。

## 交付

交付本次要求的高清图片、可编辑 HTML/CSS、实际使用的素材和字体许可、必要的来源记录，以及简短的修改与检查结果。失败或未进行的检查应明确写出。

制图请求只授权创作和文件交付。账号登录、上传、发布、评论和互动需要用户另行明确要求。

来源、固定版本和本地适配范围见 `sources.json`。外部原版中的默认字体、平台框架、推广语和生成后端不覆盖本技能与当前任务。
