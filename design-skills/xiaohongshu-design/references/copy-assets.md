# 文案与素材约束

## 三种内容模式

- **保真排版**：用户给出原文且未授权改写时使用。只改分段、断行和样式，原文标题、数字、单位、正文及行动引导完整保留。
- **授权改编**：用户要求精简、重写或平台化表达时使用。记录改动范围，保留事实与限制条件；不能因追求封面冲击而提高原文承诺。
- **主题创作**：用户只提供主题并要求创作时使用。将资料事实与创作表达分开，需核实的事实先查询，不能制造经历、证言、数据或截图。

价格是否显示、如何表述、是否需要行动引导都以本次任务为准。仅排版时不擅自删除金额、替换产品名或补充业务说法。

## 文案核对

每块正式文字用唯一 `data-copy` 标记，可将锁定文案保存为JSON数组：

```json
[
  {"id": "cover-title", "text": "本次确认的封面标题"},
  {"id": "page-02-body", "text": "本次确认的正文"}
]
```

渲染工具对照时只忽略空白和断行，不忽略标点、数字、单位或文字差异。原文表情符号是文案的一部分时保留；不要从其他Skill自动补入表情、标签、文案或署名。

## 素材

- 记录实际使用的本地文件、来源页、作者、用途和许可；获得来源文件后查看实际画面。搜索标题和自动描述不能证明图片拍摄地点、真实性或内容。
- 事实照片和真实截图保留其事实内容。不得用生成图或重新绘制的截图证明未发生的效果、经历、使用结果或业务事实。
- 摄影题材、地点、人物与场景由本次内容决定。默认保留实拍色彩；调色和风格处理按本次方案执行，不自动套来源Skill的滤镜。
- 默认采用独立配图，不将同图改名或改裁切冒充新素材。教程或连续叙事需要复用同一主体时可以有目的地复用，并保持其事实一致。
- 不随意拉伸素材，不遮挡关键主体、图表标签或界面文字。放进卡片后检查裁切和缩小后的可读性。
- 字体使用真实文件及正确字重，核对实际字体与回退。保留字体和第三方资产的许可声明，来源不明时不要写成已授权。
