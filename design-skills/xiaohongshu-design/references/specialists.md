# 已安装的小红书专长

主入口 xiaohongshu-design 保留通用规则。以下模块均已安装；按目标选择一个主要制作路径，再衔接必要的分析或精修。

| 目标 | Skill | 选择依据 |
|---|---|---|
| 中文精确排字、自由构图、可编辑工程 | xiaohongshu-design | 默认路径，调用现有参考、封面、构图和精修模块 |
| 插画或手绘卡片组图 | [baoyu-xhs-images](../../baoyu-xhs-images/SKILL.md) | 已明确选择生成式卡片，按风格×布局组织系列 |
| 生成式封面或视觉素材 | [baoyu-cover-image](../../baoyu-cover-image/SKILL.md) | 本次需要生成图片，比例服从当前任务 |
| 流程、对比或层级信息图 | [baoyu-infographic](../../baoyu-infographic/SKILL.md) | 明确选择生成式信息图；精确可编辑内容继续代码排版 |
| Markdown快速分页与13套主题 | [auto-redbook](../../auto-redbook/SKILL.md) | 选用其主题和5种封面布局，不强制套模板 |
| 静纸、实证或跨平台的已选风格 | [blcaptain-style-skill](../../blcaptain-style-skill/SKILL.md) | 使用其确定性引擎，保留本次事实和内容边界 |
| 从素材到完整内容策划 | [xhs-writer](../../xhs-writer/SKILL.md) | 用户授权创作或改写；不是保真排版的必经步骤 |
| Markdown文字知识卡与9套主题 | [xhs-note-creator](../../xhs-note-creator/SKILL.md) | tensorslab文字排版路径，内置中文字体 |
| 插画卡片的另一套组织流程 | [xhs-images-design](../../xhs-images-design/SKILL.md) | 与Baoyu组图按任务择一，避免重复生成 |

已确认风格时直接采用，不重复要求用户从所有主题中再选一遍。模板、字体和配色是本次可选方案，不恢复任何历史产品的固定规则。

所有模块遵循 [本地专长调用规则](specialist-policy.md)。已有封面判断仍使用 xhs-cover-lab；原来的三个设计辅助模块继续用于参考、构图与精修。
