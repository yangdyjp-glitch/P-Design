# 小红书版式与观看检查

## 观看条件

分别检查封面缩略图、打开后的单页阅读与连续翻页。只在电脑大图上成立的排版不算完成。

本工作流默认 3:4、1080 × 1440 CSS px，按 2 倍导出为 2160 × 2880。其他尺寸或比例按用户要求执行，整套一般保持一致。不要把社区工具的尺寸、标题字数或图片数量写成平台硬限制；需要当前平台限制时另查官方资料或实际界面。

## 试排起点

以下仅用于1080 px宽画布的试排，最终以实际字形、文案和预览为准：

| 角色 | 常见起点 |
|---|---|
| 标题 | 约72–132 px；短标题可以更大 |
| 次级标题 | 约44–64 px |
| 连续正文 | 约38–48 px；正文多时先增页或重分区 |
| 页边留量 | 约56–80 px；按图文关系与裁切调整 |
| 正文行距 | 约1.4–1.65；按字体、宽度和底色调整 |

不要将网页16 px正文、移动端触控尺寸或英文字母行长直接当作图片排版标准。中文不要照搬英文大写、斜体或负字距配方。英文、数字、标点与中文混排要实际查看。

## 封面

- 最重要的主题词在180 px宽缩略图中仍能辨认；不要让副标签、装饰和署名争抢主标题。
- 明确视觉中心：主体图、关键字、数字或有真实依据的结果；不是每次都放大同一种元素。
- 标题提出的利益、问题或结论应在组图里有内容支撑。没有依据时不加“亲测”、收益、效果、排名或极端判断。
- 使用照片时预先考虑主体位置与文字区域，避免遮脸、关键细节或截图文字。

## 内页

- 使用标题、证据、步骤、对比、清单、关系图等与内容相符的结构。每页一个主要阅读任务，保留必要上下文。
- 同类信息使用一致的对齐与层级；不同重要程度不强行做成等大的卡片。
- 使用大小、字重、色彩、位置与间距共同建立层级，不能只靠加粗或色框。
- 邻页不必强制不同，也不应无理由复制。重复用于识别，变化用于表达信息差异。
- 密度服务于理解。留白不是固定百分比，饱满也不是把所有区域填满。

## 整套

看封面到结尾是否有明确顺序、信息是否重复或缺漏、图片与正文是否互相支持。使用统一的基础字体、配色角色与间距，保留页与页的视觉变化。

页码、页眉页脚、品牌、水印和二维码都不是默认必加项目；有明确内容需要时才设计，不用虚构的信息填空。只有一页时不强行添加滑动、关注或收藏引导。
