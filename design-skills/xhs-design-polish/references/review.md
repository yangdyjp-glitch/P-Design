# 交付检查

按影响顺序处理问题，并给出画面、位置或提取结果作为依据。

1. **内容**：锁定文案完整，数字、单位、限制条件和本次价格要求匹配；没有新增未经提供的事实或承诺。
2. **阅读**：封面主题在缩略图中可辨认，正文在手机预览可读，阅读顺序和语义断句成立。
3. **视觉**：主次、分组、字重、光学对齐、疏密和裁切合理，整套统一且有内容驱动的变化。
4. **素材**：照片和截图角色准确，来源与许可有记录，字体实际加载，没有把示意图冒充事实证据。
5. **结构**：没有缺字、文字越界、遮挡、内部裁切、缺图、重复文案标记或导出尺寸错误。
6. **交付**：图片与源文件可定位，所需素材和许可齐备，报告只声明实际完成的检查。

工具通过只能证明它检查到的结构条件。没有看过的图、没有执行的对照和失败的检查不能记录为通过。
