# 文字与空间检查

## 先看关系

- 暂时忽略文字细节，主视觉、次级信息和正文组是否仍有明确顺序？
- 相关信息是否自然靠近，不同信息是否有必要的分隔？不要用套框补救弱分组。
- 疏密有没有节奏？重要与次要内容是否被同样字号、同样间距、同样卡片压成等权？
- 布局是否来自内容关系，而不是默认网格或模板？变化是否真的帮助阅读？

## 再看文字

- 主标题、副标题、正文与辅助信息的角色是否可辨认，同角色样式是否一致？
- 字号、字重、颜色与空间共同构成层级，不靠一味放大、加粗或增加字体数量。
- 核对真实加载的字体及实际字重。中文、英文、数字、标点和表情符号分别检查，不用字体家族名称冒充加载结果。
- 根据实际中文词组、宽度和字形处理断行；不要拆开关键数量和单位，不把英文字符行长标准套用到中文卡片。
- 深底浅字要实际查看笔画、字重、字距与行距。增加对比或调整文字区，不靠低对比装饰色承担长正文。
- 光学对齐要看成图：标点、数字、不同字形和图片重心可能需要小幅校正。

## 最后看素材与空间

- 主体裁切是否仍保留必要内容，截图内文字是否真的能读？
- 图与文是否有前后关系且没有互相遮挡？阴影、边框和装饰是否有用途？
- 文字过多优先重分区或增页；不要擅自改写、删掉事实或无限缩字。
- 继承本次的基础字体、配色角色与间距，按内容决定哪些页面重复、哪些变化。
