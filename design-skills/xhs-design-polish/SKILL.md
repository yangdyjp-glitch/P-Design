# 小红书排版精修

本地提炼自 Impeccable 的 typeset、layout 和 polish 方法。只使用静态设计部分，不依赖其二进制工具、网页运行时或交互检测。

先读取本次锁定文案、视觉规范和实际渲染，再读 [文字与空间检查](references/type-layout.md)。已有明确审查问题时先处理影响阅读和事实的问题。

精修保留已确认的字体、配色、素材和内容边界。需要替换整套身份时说明这是重新设计，并以用户当前授权为准，不能藏在局部修饰中。

检查分两次看：先独立判断画面主次与阅读，再看字体加载、提取文字和边界数据；技术报告不能替代视觉判断。普通任务由当前执行者完成，不强制使用子代理。

批量修正同一轮观察到的问题，然后重新查看高清图、360 px阅读预览、180 px缩略图和系列总览。达到本次要求即交付，不强制无限加轮次或不断提出新优化。

使用 [交付检查](references/review.md) 记录实际检查结果与剩余限制。
